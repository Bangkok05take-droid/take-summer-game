# たけ少年のなつやすみ

スマホのブラウザで遊べる、全10ステージの2D横スクロールアクションです。
坊主頭のたけ少年が、夏休みの田舎を冒険します。絵も音もすべてプログラムで描いたり鳴らしたりしているので、画像や音のファイルはありません。

## 起動方法

ビルドは不要です。フォルダをそのまま Web サーバーで配信してください。

```sh
npx http-server -p 8123 .
# → PC: http://localhost:8123/
# → スマホ: 同じ Wi-Fi で http://<PCのIPアドレス>:8123/
```

GitHub Pages などの静的ホスティングにそのまま置いても動きます。`index.html` をブラウザで直接開いても遊べます。

## 遊び方

- スマホは横向きで遊びます。左下の ◀ ▶ で移動、右下の「ジャンプ」で跳びます(長く押すと高く跳びます)。
- PC: ← → (A / D) で移動、スペース / ↑ / Z でジャンプ、Esc / P で一時停止。
- 敵は上から踏むと倒せます。横から当たったり、穴や水に落ちたりするとミスです。残機はなく、すぐにやり直せます。
- 風鈴がチェックポイント、旗がゴールです。スイカのかけらは集めなくてもクリアできます。
- クリア状況・チェックポイント・音の設定は端末(localStorage)に保存されます。タイトルの「つづきから」で再開できます。

## 調整する場所

| 調整したいこと | ファイル |
| --- | --- |
| ステージの配置・敵・足場・ヒント | `js/stages.js`(記号の説明は冒頭のコメント) |
| ジャンプの高さ・速さ・滑り具合・猶予時間 | `js/engine.js` の `PHYS` |
| 当たり判定の大きさ | `js/engine.js` の `stepPlayer` 内(「当たり判定は見た目より少し小さめ」) |
| 色・背景・キャラクターの絵 | `js/render.js` |
| 効果音 | `js/audio.js` |
| ボタンの大きさ・位置 | `css/style.css` の `.vbtn` |

例: 「ジャンプをもう少し軽く」→ `PHYS.gravityDown` を少し下げる / `jumpSpeed` を上げる。
「7面が難しすぎる」→ `js/stages.js` の7面で、穴(`..`)を狭くする、足場(`##`)を広くする、チェックポイント `C` を増やす。

## 確認用ツール

ステージを変更したら、ゴールまで到達できるかを自動で確認できます。

```sh
node tools/check-stages.js          # 全ステージを、実際と同じ物理で探索してゴール到達を確認
node tools/check-stages.js 7        # 7面だけ
node tools/check-stages.js --save   # 見つけた手順を tools/solutions.json に保存
node tools/browser-test.js          # ブラウザで操作・保存・全10面クリアなどを確認(サーバー起動と Playwright が必要)
```

## ファイル構成

```
index.html        画面の骨組み
css/style.css     画面・ボタンのデザイン
js/engine.js      物理・当たり判定・ステージ読み込み(Node でも動く)
js/stages.js      全10ステージのデータ
js/render.js      描画(キャラクター・背景・タイル)
js/audio.js       効果音(Web Audio)
js/input.js       タッチボタンとキーボード
js/main.js        画面の切り替え・進行・セーブ
tools/            自動チェック用スクリプト
```
