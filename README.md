# たけ少年とサイちゃんの日本大冒険

スマホのブラウザで遊べる、全10ステージの自動走行2Dアクションです。
日本を旅行中にはぐれてしまったサイちゃんを、たけ少年が走って迎えに行きます。
浅草・富士山・嵐山・道頓堀・奈良公園・上高地・夢の遊園地・沖縄・北海道をめぐり、最後は富士山の見える花火大会へ。
絵も音もすべてプログラムで描いたり鳴らしたりしているので、画像や音のファイルはありません。

> 修正前の「たけ少年のなつやすみ」(左右移動版)はコミット `ad5c666` です。
> 戻したいときは `git checkout ad5c666 -- .` で当時のファイルを取り出せます。

## 起動方法

ビルドは不要です。フォルダをそのまま Web サーバーで配信してください。

```sh
npx http-server -p 8123 .
# → PC: http://localhost:8123/
# → スマホ: 同じ Wi-Fi で http://<PCのIPアドレス>:8123/
```

GitHub Pages などの静的ホスティングにそのまま置いても動きます。`index.html` をブラウザで直接開いても遊べます。

## 遊び方

- スマホは横向きで遊びます。たけは**自動で右へ走ります**。
- 左下の「ダッシュ」を押している間は、なめらかに加速して最大1.5倍の速さに。ジャンプも遠くまで届きます。
- 右下の「ジャンプ」は長く押すと高く、短く押すと低く跳びます。ダッシュとの同時押しもできます。
- PC: Space / ↑ でジャンプ、Shift / → でダッシュ、Esc / P で一時停止。
- 敵は上から踏んで倒します。**少年のときに3体**倒すと**大人のたけ**に変身。大人は1回だけぶつかっても平気(少年に戻り、2秒間は無敵)。
- **スイカのかけら5個で8秒間無敵**。体当たりで敵を倒せ、トゲも平気です。
- 穴や水に落ちると、大人でも無敵でもミス。残機はなく、風鈴(チェックポイント)からすぐ再挑戦できます。
- ゴールではサイちゃんが待っています。10面クリアで2人で花火を見るエンディング。
- クリア状況・チェックポイント・音の設定は端末(localStorage)に保存されます。タイトルの「つづきから」で再開できます。

## 調整する場所

| 調整したいこと | ファイル |
| --- | --- |
| ステージの配置・敵・足場・ヒント | `js/stages.js`(記号の説明は冒頭のコメント) |
| 走る速さ・ダッシュ・ジャンプ・変身や無敵の数と時間 | `js/engine.js` の `PHYS` |
| 当たり判定の大きさ | `js/engine.js` の `stepPlayer` 内(「当たり判定は見た目より少し小さめ」) |
| 色・背景・キャラクターの絵 | `js/render.js` |
| 効果音 | `js/audio.js` |
| ボタンの大きさ・位置 | `css/style.css` の `.vbtn` |

例: 「もう少しゆっくり走りたい」→ `PHYS.runSpeed` を下げる(`dashSpeed` も1.5倍に合わせる)。
「7面が難しすぎる」→ `js/stages.js` の7面で、穴(`.....`)を狭くする、チェックポイント `C` を増やす。

## 確認用ツール

ステージを変更したら、ゴールまで到達できるかを自動で確認できます。

```sh
node tools/check-stages.js          # 全ステージを実際と同じ物理で探索。どのタイミングで来ても待たずに進めるか、1〜5面はダッシュなしで行けるかも確認
node tools/check-stages.js --quick  # タイミング確認を省いた速い確認
node tools/check-stages.js 7        # 7面だけ
node tools/check-stages.js --save   # 見つけた手順を tools/solutions.json に保存
node tools/browser-test.js          # ブラウザで自動走行・ダッシュ・変身・無敵・保存・全10面クリアなどを確認(サーバー起動と Playwright が必要)
```

## ファイル構成

```
index.html        画面の骨組み
css/style.css     画面・ボタンのデザイン
js/engine.js      物理・当たり判定・ステージ読み込み(Node でも動く)
js/stages.js      全10ステージのデータ
js/render.js      描画(キャラクター・背景・タイル)
js/audio.js       効果音(Web Audio)
js/input.js       タッチボタンとキーボード
js/main.js        画面の切り替え・進行・セーブ
tools/            自動チェック用スクリプト
```
