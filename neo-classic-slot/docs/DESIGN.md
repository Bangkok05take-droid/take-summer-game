### 配列の仕組み

| 場所 | 並び（下→上） | 狙い |
|---|---|---|
| 左 | **チェリー / BAR / ブドウ / リプレイ / 山**（1〜5、9〜13） | BAR狙いで「通常=BAR下段」「チェリー成立=チェリー下段」「山小役=山が滑って中段」「ボーナス=山が下段まで大滑り」 |

## 2. BETと有効ライン

| BET | 有効ライン |
|---|---|
| 1枚 | 中段 |
| 2枚 | 中段・上段・下段 |
| 3枚（MAX BET） | 5ライン（中段・上段・下段・右下がり・右上がり） |

- 払い出し枚数はBET枚数によらず同じ。役は有効ライン上でのみ成立。停止制御は有効ラインに合わせて引き込み・回避する。
- 取りこぼし無し（ブドウ・リプレイ100%）を保証するのは3枚掛けのみ。
- 操作: **BET**＝1枚ずつ（最大3）／**左の物理レバー**＝現在のBETでレバーON（0枚なら開始しない）／**大きなLEVER ON**＝不足分を追加BETしてMAX BET＋レバーON／**STOP×3**＝押した順に停止。リプレイは前回と同じBETで自動開始。

## 3. 役と確率（分母65536）

| 役 | 図柄（左-中-右） | 払い出し | 確率 | 取りこぼし（3枚掛け） |
|---|---|---:|---|---|
| BIG | 赤7-赤7-赤7 | ボーナス | 655 → 1/100.05 | 目押し必要（持ち越し） |
| REG | 赤7-赤7-BAR | ボーナス | 655 → 1/100.05 | 目押し必要（持ち越し） |
| ブドウ | ブドウ×3 | 8枚 | 10923 → 1/6.0 | 無し |
| チェリー | チェリー-チェリー-ANY | 2枚 | 2185 → 1/30.0 | 左BAR狙いで無し |
| ベル | ベル×3 | 14枚 | 64 → 1/1024 | 有り |
| **山** | 山×3（**中リール中段を通る3ラインのみ**） | **3枚** | **2185 → 1/30.0** | 有り（BAR狙いで約39%） |
| リプレイ | リプレイ×3 | 再遊技 | 8978 → 1/7.3 | 無し |

- **ボーナス持ち越し中（成立ゲームの次ゲーム以降）は目押しで必ず揃う**: 各リールでボーナス図柄（BIG 7・7・7 / REG 7・7・BAR）が**中段の1〜3コマ上（上段〜枠のすぐ上）にある時に押せば**、押し順・BET枚数・同時成立小役にかかわらず必ず揃う（`NCS.CARRY_AIM`、verify.js で総当たり確認）。目押しされたボーナスは小役より優先。成立ゲームは従来どおりリーチ目優先。
  - 7の下にブドウが並ぶ配列のため、ブドウが同時に揃ってしまう停止（例: REGの中段揃い）は使わず、揃うラインは先読みで選ぶ。
- チェリー: 左チェリーと**同じ有効ライン上の中チェリー**で成立（右不問）。
- 山小役は中段・右下がり・右上がりのみ → 山小役では中の山は必ず中段。中の山の上段・下段停止は特別な目。

## 4. チャンス目とリーチ目

### チャンス目（その小役かボーナスの時だけ停止）

| 名称 | 条件 | 停止を許す内部 |
|---|---|---|
| 左チェリー出現 | 左リール窓にチェリー | チェリー or ボーナス |
| 左山出現 | 左第1停止で左リール窓に山 | 山小役 or ボーナス |
| 逆押し右中段7 | 右第1停止で右中段に赤7 | ブドウ or ボーナス |

### 確定リーチ目（ボーナス非成立では絶対に停止しない）

| 名称 | 条件 | 確定 | 確定する停止 |
|---|---|---|---|
| チェリー外れ | 左にチェリー、かつチェリー非入賞 | BIG/REG | 順押し第2停止 |
| チェリー外れ＋中段7 | 上記＋中リール中段に赤7 | BIG/REG | 順押し第2停止 |
| 挟み打ち山否定 | 左→右→中、左山下段、右上段が山でない | BIG/REG | 第2停止（右） |
| 山V字 | 左上・中下・右上が山 | BIG/REG | 第3停止 |
| 大山（中山上段） | 左下・中上・右下が山 | **BIGのみ** | 第3停止 |
| 谷（中山下段） | 左中・中下・右中が山 | **BIGのみ** | 第3停止 |
| 小山 | 左中・中上・右中が山 | BIG/REG（REG寄り） | 第3停止 |
| BAR一直線 | BAR-BAR-BAR が有効ライン上 | BIG/REG | 第3停止 |
| 逆押し右中段7・ブドウ否定 | 右第1停止で右中段7、ブドウ非入賞 | BIG/REG | 第2停止（中でブドウの全ラインが消える形を優先） |
| 逆押し右上段7 | 右第1停止で右上段に赤7 | **REGのみ** | 第1停止 |

「第n停止で確定」は停止制御が自動判定: 残りのリールがどこに止まっても必ず確定目になる停止でランプ点灯。

## 5. 停止制御（`js/core/reelControl.js`）

探索方式。押下位置から0〜4コマ先の5候補それぞれについて、残りのリールが「どの順番・どのタイミングで押されても」到達しうる最終出目を評価し、
1. **最悪ケース**（停止禁止出目を出さない／成立小役を取りこぼさない）が最も良い候補
2. **平均評価**（引き込み・狙いの目・見た目の基本形）が最も良い候補
3. すべりが少ない候補

の順で選ぶ。最悪ケースは「停止禁止」と「成立小役が揃うか」だけで評価し、見た目の好み（BAR下段・右7下段・中段ライン優先など）は平均評価にのみ効かせる。

| 最終出目 | 評価 |
|---|---|
| 成立していない役が揃う／許可されないリーチ目・チャンス目 | 停止禁止 |
| 成立小役が揃う | +100 |
| 成立ボーナスが揃う | +50 |
| 出目モードの狙いの目 | +80 × 重み |
| モード外の確定目 | −5 |
| 小役が中段ライン／左BAR下段／逆押し右7下段 | +3／+1／+1 |

## 6-2. ジャグ連チャンスとプレミア演出（第3段階）

### ジャグ連チャンス（`js/core/jugren.js`）

| 項目 | 仕様 |
|---|---|
| 突入 | BIG終了後のみ（REG終了後は通常へ）。BIG終了ごとに新たなチャンス |
| 抽選 | 1G目 20% → 2G目 25% → 3G目 1/3（未当選時のみ次へ。累計60%） |
| 振り分け | BIG 2/3・REG 1/3 |
| チャンス中の小役 | 通常どおり抽選（ボーナスはジャグ連抽選のみで決定） |
| 先行抽選 | BIG開始時にチャンス1G目の当否を抽選・保持（1G目で再抽選しない） |
| 無音先ペカ | 1G目BIG当選の10%で、BIG消化中のどこかのレバーONで全音停止＋告知ランプ点灯。次のレバーONで音が戻る（オート中も同じ） |
| 復活フリーズ | チャンス中BIG当選の10%（無音先ペカとは同時発生しない）。当選を隠して1〜3G目はハズレに見せ（停止制御にボーナスを渡さない）、4G目のレバーONでフリーズ「復活！ nGAME目でBIG当選！」。REGでは発生しない。当選後は再抽選しない |

### プレミア演出（`js/effects/premium.js`・すべてBIG確定）

BIG成立ゲームのレバーONで、内部抽選とは別に演出抽選する。

| 演出 | 内容 | 通常時 | ジャグ連中 |
|---|---|---:|---:|
| プチュンフリーズ（レバーONフリーズ） | レバーONで「プチュン」→ 照明・画面が暗転し約1秒の完全な静寂 → LUCKY CHANCE が紫に激しく発光 → 金色の光と「PREMIUM BIG BONUS」→ 通常のBIG確定状態へ（約4秒・NEO独自の合成音とCSS演出） | 2% | 5% |
| 遅れ | リール始動が約0.45秒遅れる（告知は通常タイミング） | 5% | 12% |
| 第2停止プレミア | 第2停止で特殊告知 | 3% | 10% |
| スマホ振動 | 告知時に長い振動（Vibration API 対応端末のみ） | 5% | 12% |
| 復活フリーズ | 上表 | — | ジャグ連BIGの10% |
| 無音先ペカ | 上表 | — | 1G目BIGの10% |

### サウンド（`js/audio/sound.js` / `js/audio/bgm.js`）

| 場面 | 音 |
|---|---|
| 通常時 | 控えめなBGM（`CONFIG.NORMAL_BGM` でON/OFF） |
| BIG中 / REG中 | 明るく速いBGM / 軽快なBGM |
| ジャグ連チャンス中（復活待ち含む） | 短調の緊張感あるBGM |
| 告知ランプ | 「ペカッ」上昇音＋きらめき |
| 払い出し | 電子音＋金属音を枚数分（新しい払い出しで前回分をフェードアウト。オート中は間隔を詰める） |
| ドル箱完成 / 万枚達成 | メダル音＋上昇チャイム / ファンファーレ |
| プレミア | プチュン（短い下降電子音）・紫ランプ（低音のうねり）・金色（上昇ファンファーレ）、復活・第2停止の専用音 |
| 無音先ペカ | マスター音量0で全停止（BGMは裏で進行）、次のレバーONで復帰 |

BGMは状態が変わるとクロスフェードで切替。オート中はレバー音・第1〜2停止音を省略してテンポを保つ。データ画面からサウンドON/OFF（設定は保存）。

## 7. 筐体の数字表示とドル箱

| 表示 | 内容 |
|---|---|
| CREDIT | クレジット（000〜999の3桁）。1,000枚に達したら1,000枚ずつドル箱へ |
| ドル箱カウンター | 筐体下部の「× n BOX」。タップでドル箱専用画面 |

| データ画面 | 総ゲーム数・BIG/REG回数と確率・ボーナス履歴・ドル箱・総所持枚数・最高到達枚数・差枚 |

### ドル箱システム（`js/core/wallet.js` / `js/view/dollarBox.js`）

| 項目 | 仕様 |
|---|---|
| 1箱 | 1,000枚 |
| 総所持枚数 | クレジット＋ドル箱内枚数 |
| 完成箱数 | ドル箱内枚数 ÷ 1,000（切り捨て） |
| 繰り上がり | 払い出しでクレジットが1,000以上になったら1,000枚ずつドル箱へ（一度に複数箱も可）。例: 995＋15 → CREDIT 10・1箱 |
| 自動補充 | BETに必要なクレジットが無い時、ドル箱から必要枚数だけ補充。1,000枚を割ると完成箱数が減る（端数は作りかけの箱として表示） |
| 貸出 | クレジットもドル箱も空の時のみ500枚（投資として集計） |
| 記録 | 最高到達枚数・最高ドル箱数・累計獲得枚数は別管理（取り崩しても残る） |
| 完成演出 | 金色の光＋メダル山盛りのドル箱＋「DOLLAR BOX COMPLETE!」＋完成音（約1.6秒、操作を止めない） |

| セーブ | クレジット・ドル箱・総所持枚数・最高到達枚数・最高ドル箱数・累計獲得枚数を localStorage に保存し、起動時に復元。データ画面から初期化可 |

## 9. モジュール構成

| 層 | ファイル | 役割 |
|---|---|---|
| 設定 | `js/config/*.js` | 図柄・配列・役・確率・リーチ目・筐体スキン・ゲーム設定 |
| 抽選 | `js/core/lottery.js` | 内部抽選（停止制御から独立） |
| 判定 | `js/core/judge.js` | 入賞ライン（有効ライン別）・リーチ目判定 |
| 停止制御 | `js/core/reelControl.js` | すべり決定・確定判定 |
| 進行 | `js/core/game.js` | BET・レバー・停止・ボーナス・メダル。DOM非依存 |
| オート | `js/core/autoPlay.js` | ボーナス中のオート消化 |
| 検証 | `js/core/verifier.js`, `tools/verify.js` | 総当たり検証 |
| 配列調整 | `tools/search-strips.js` | 配列の自動調整（局所探索） |
| 描画 | `js/view/*.js` | リール・図柄・筐体パーツ・UI・データ画面 |
| 演出 | `js/effects/effects.js` | 告知ランプ・振動 |
| 音 | `js/audio/sound.js` | チャンネル別の音量・払い出し音の重なり防止 |
| デバッグ | `js/debug/debugPanel.js` | 強制当選・内部状態・検証 |
