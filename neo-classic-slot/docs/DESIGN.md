### 配列の方針（Ver.10・ユーザー指定の位置固定版）

- **赤7・BAR・チェリーはオリジナルジャグラーと同じ位置、山は 左18・8・1／中13・5／右15・9・2 に固定**（ユーザー指定）。
  リプレイ・ブドウ・ベルはその間に配置し、同じ図柄が縦に連続しない。旧サイ図柄はリプレイ。
- 右リールは赤7（20）とBAR（19）を1組にまとめて狙いやすく。右0番のブドウで「上ブドウ・中赤7・下BAR」の形。
- **ブドウ・リプレイの取りこぼしは許容**（出目・演出を優先）。順押し・逆押し・挟み打ち（左か右から停止）を優先して揃え、
  中押しは小役の取りこぼしを気にしない。入賞率は `node tools/verify.js` で表示（左・右から: ブドウ約99.6%・リプレイ約98.5%）。
- 左右リールの山は上段・下段が基本形（中段は避ける）。山小役は左BARが滑って左上段に山。
- **左BAR狙いのハズレ時の基本停止形**（Ver.11）: 15番BAR狙い → 上リプレイ(17)／中ブドウ(16)／下BAR(15)、
  4番BAR狙い → 上BAR(4)／中ブドウ(3)／下リプレイ(2)。チェリー・山・ブドウ・リプレイ成立時は引き込める範囲でその役を優先
  （`NCS.LEFT_BAR_AIM_STOPS`、制御の見た目評価 +4。役の引き込み +100 より弱い）。
- **ボーナス・レア小役の目押しサポート**（Ver.13）: チェリー・山は4コマ滑りで引き込める範囲で引き込む。ボーナスは成立ゲームでも、
  ボーナス図柄を中段の1〜3コマ上で押すと揃える方向に滑らせる（BAR狙いのリーチ目演出はそのまま）。
- **LUCKY CHANCE の後ペカ**（Ver.13）: 第3停止のボタンを離した瞬間に点灯。リール速度は45回転。
- **目押し補正**（Ver.12）: スマホのタッチ・描画の遅れ分（`CONFIG.STOP_LAG_MS` = 50ms）だけ前の位置を押下位置にする。
  補正で目標が1コマ未満手前になった時はその場で止める（停止バウンドに紛れる）。

## 2. BETと有効ライン

| BET | 有効ライン |
|---|---|
| 1枚 | 中段 |
| 2枚 | 中段・上段・下段 |
| 3枚（MAX BET） | 5ライン（中段・上段・下段・右下がり・右上がり） |

- 払い出し枚数はBET枚数によらず同じ。役は有効ライン上でのみ成立。停止制御は有効ラインに合わせて引き込み・回避する。
- 取りこぼし無し（ブドウ・リプレイ100%）を保証するのは3枚掛けのみ。
- 操作: **BET**＝1枚ずつ（最大3）／**左の物理レバー**＝現在のBETでレバーON（0枚なら開始しない）／**大きなLEVER ON**＝不足分を追加BETしてMAX BET＋レバーON／**STOP×3**＝押した順に停止。リプレイは前回と同じBETで自動開始。

## 3. 役と確率（分母65536）

| 役 | 図柄（左-中-右） | 払い出し | 確率 | 取りこぼし（3枚掛け） |
|---|---|---:|---|---|
| BIG | 赤7-赤7-赤7 | ボーナス | 655 → 1/100.05 | 目押し必要（持ち越し） |
| REG | 赤7-赤7-BAR | ボーナス | 655 → 1/100.05 | 目押し必要（持ち越し） |
| ブドウ | ブドウ×3 | 8枚 | 10923 → 1/6.0 | 無し |
| チェリー | チェリー-チェリー-ANY | 2枚 | 2185 → 1/30.0 | 左BAR狙いで無し |
| ベル | ベル×3 | 14枚 | 64 → 1/1024 | 有り |
| **山** | 山×3（**中リール中段を通る3ラインのみ**） | **3枚** | **2185 → 1/30.0** | 有り（BAR狙いで約39%） |
| リプレイ | リプレイ×3 | 再遊技 | 8978 → 1/7.3 | 無し |

- **ボーナス持ち越し中（成立ゲームの次ゲーム以降）は目押しで必ず揃う**: 各リールでボーナス図柄（BIG 7・7・7 / REG 7・7・BAR）が**中段の1〜3コマ上（上段〜枠のすぐ上）にある時に押せば**、押し順・BET枚数・同時成立小役にかかわらず必ず揃う（`NCS.CARRY_AIM`、verify.js で総当たり確認）。目押しされたボーナスは小役より優先。成立ゲームは従来どおりリーチ目優先。
  - 7の下にブドウが並ぶ配列のため、ブドウが同時に揃ってしまう停止（例: REGの中段揃い）は使わず、揃うラインは先読みで選ぶ。
- チェリー: 左チェリーと**同じ有効ライン上の中チェリー**で成立（右不問）。
- 山小役は中段・右下がり・右上がりのみ → 山小役では中の山は必ず中段。中の山の上段・下段停止は特別な目。

## 4. チャンス目とリーチ目

### チャンス目（その小役かボーナスの時だけ停止）

| 名称 | 条件 | 停止を許す内部 |
|---|---|---|
| 左チェリー出現 | 左リール窓にチェリー | チェリー or ボーナス |
| **ボーナス図柄揃い** | どのラインでも赤7・BARだけが3つ並ぶ（7・7・BAR、BAR・7・7、BAR一直線など） | **BIG/REGのみ（確定）** |
| **左中段チェリー** | 左リール中段にチェリー（チェリー成立・REG時は滑って上段か下段） | **BIGのみ（確定）** |
| 左山出現（上段・下段） | 左第1停止で左上段・下段に山（BAR上段ビタ→4コマ滑って⑧番の山が上段／BAR枠上→①番の山が下段） | 山小役 or ボーナス |

## 5. 停止制御（`js/core/reelControl.js`）

探索方式。押下位置から0〜4コマ先の5候補それぞれについて、残りのリールが「どの順番・どのタイミングで押されても」到達しうる最終出目を評価し、
1. **最悪ケース**（停止禁止出目を出さない／成立小役を取りこぼさない）が最も良い候補
2. **平均評価**（引き込み・狙いの目・見た目の基本形）が最も良い候補
3. すべりが少ない候補

の順で選ぶ。最悪ケースは「停止禁止」と「成立小役が揃うか」だけで評価し、見た目の好み（BAR下段・右7下段・中段ライン優先など）は平均評価にのみ効かせる。

| 最終出目 | 評価 |
|---|---|
| 成立していない役が揃う／許可されないリーチ目・チャンス目 | 停止禁止 |
| 成立小役が揃う | +100 |
| 成立ボーナスが揃う | +50 |
| 出目モードの狙いの目 | +80 × 重み |
| モード外の確定目 | −5 |
| 小役が中段ライン／左BAR下段／逆押し右7下段 | +3／+1／+1 |

## 9. モジュール構成

| 層 | ファイル | 役割 |
|---|---|---|
| 設定 | `js/config/*.js` | 図柄・配列・役・確率・リーチ目・筐体スキン・ゲーム設定 |
| 抽選 | `js/core/lottery.js` | 内部抽選（停止制御から独立） |
| 判定 | `js/core/judge.js` | 入賞ライン（有効ライン別）・リーチ目判定 |
| 停止制御 | `js/core/reelControl.js` | すべり決定・確定判定 |
| 進行 | `js/core/game.js` | BET・レバー・停止・ボーナス・メダル。DOM非依存 |
| オート | `js/core/autoPlay.js` | ボーナス中のオート消化 |
| 検証 | `js/core/verifier.js`, `tools/verify.js` | 総当たり検証 |
| 配列調整 | `tools/search-strips.js` | 配列の自動調整（局所探索） |
| 描画 | `js/view/*.js` | リール・図柄・筐体パーツ・UI・データ画面 |
| 演出 | `js/effects/effects.js` | 告知ランプ・振動 |
| 音 | `js/audio/sound.js` | チャンネル別の音量・払い出し音の重なり防止 |
| デバッグ | `js/debug/debugPanel.js` | 強制当選・内部状態・検証 |
