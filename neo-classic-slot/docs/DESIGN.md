### 配列設計のルール

| ルール | 理由 |
|---|---|
| ブドウ・リプレイは各リール5個、間隔5コマ以内 | 中段（どの行でも）に必ず引き込める → 取りこぼし無し |
| 右リールはブドウとリプレイを隣接させない | ブドウ中段揃いの時に上下段でリプレイが揃わないようにする |
| 左チェリーは BAR の直下（左3/左12）、ブドウ・リプレイとは非隣接 | 「左BAR狙いでチェリー」を実現しつつ、小役を中段に揃える時チェリーが窓に入らない |
| 中チェリーは4個・間隔6コマ以内（2,7,12,17） | 左チェリー停止時、対応ラインの中チェリーを必ず引き込める（＝チェリー成立時に外れ目が出ない） |
| 赤7: 左2・中2・右3 / BAR: 各2 | ボーナスは目押し（4コマすべりの範囲で引き込み） |

### チェリーの成立ライン（明確な定義）

**左リールのチェリーと、同じ有効ライン上の中リールにチェリーがあれば成立。** 右リールは問いません。

| 左チェリーの位置 | 成立する中チェリーの位置 |
|---|---|
| 上段 | 上段（上段ライン）または 中段（右下がり） |
| 中段 | 中段（中段ライン） |
| 下段 | 下段（下段ライン）または 中段（右上がり） |

## 3. 内部抽選

- レバーON時に1回だけ抽選（`js/core/lottery.js`）。停止制御はその結果（フラグ）を受け取るだけ。
- ボーナス成立後は揃うまで**持ち越し**。持ち越し中は小役のみ抽選（ボーナス重複なし）。
- 小役とボーナスが同時に内部中の場合は小役を優先して揃える。

## 4. リーチ目一覧

すべて**ボーナス非成立時は停止禁止**（停止制御で絶対に出ないことを総当たり検証済み）。

| ID | 名称 | 成立条件 | 確定ボーナス | 主な確定タイミング |
|---|---|---|---|---|
| CHERRY_MISS | チェリー外れ | 左リールにチェリーが見えていて、中リールに対応チェリーが無い | BIG/REG | 順押しの**第2停止**（ペカリ） |
| BAR_STEP | BAR段違い | 左中段BAR ＋ 中上段BAR（右不問） | BIG/REG | 左・中が止まった時点（2確） |
| YAMAGATA | 山型 | 7/BAR が 左下段・中上段・右下段 | BIG/REG | 第3停止 |
| OYAMA | 大山 | 山図柄が 左下段・中上段・右下段 | **BIGのみ** | 第3停止 |
| KOYAMA | 小山 | 山図柄が 左中段・中上段・右中段 | BIG/REG（REG期待度高） | 第3停止 |
| BAR_LINE | BAR一直線 | BAR-BAR-BAR が有効ライン上（非入賞） | BIG/REG | 第3停止 |
| REVERSE_7 | 逆押し右中段7 | **右第1停止**で右中段に赤7 | BIG/REG | 第1停止（逆押し・右から押した時専用） |

- 「第n停止で確定」は停止制御が自動判定します: 残りのリールがどこに止まっても必ずリーチ目になる状態になった停止で確定（その停止でランプ点灯）。
- 大山はREG成立時も停止禁止（BIG確定）。

## 5. 停止制御（`js/core/reelControl.js`）

テーブルではなく**探索方式**です。押下位置から0〜4コマ先の5候補それぞれについて、残りのリールが「どの順番・どのタイミングで押されても」到達しうる最終出目を評価し、

1. **最悪ケースが最も良い候補** … 停止禁止出目を絶対に出さない／ブドウ・リプレイを必ず揃える
2. **平均が最も良い候補** … 引き込める役・狙いのリーチ目をできるだけ出す
3. **すべりが少ない候補** … 自然な停止

の優先順で選びます。最終出目の評価:

| 出目 | 点数 |
|---|---|
| 成立していない役が揃う | 停止禁止 |
| ボーナス非成立でリーチ目／REGで大山 | 停止禁止 |
| 成立小役が揃う | +100 |
| 成立ボーナスが揃う | +50 |
| 出目モードのリーチ目 | +30 |
| モード外のリーチ目 | −5 |

順押し・逆押し・挟み打ち・中押しのすべてに同じ仕組みで対応します。配列やリーチ目を変更してもテーブルを作り直す必要はありません。評価値はフラグ×モードごとにメモ化しています。

## 8. 筐体の数字表示

| 表示 | 内容 |
