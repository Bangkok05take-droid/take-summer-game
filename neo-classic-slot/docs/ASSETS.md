# 画像素材一覧（正式筐体デザイン用）

基準デザイン: `assets/design/reference_cabinet.jpg`（1080×1920 に正規化）

- **座標はすべてデザイン座標（1080×1920）**。筐体ごと等倍縮小して表示するので、素材は下表のサイズで作れば位置合わせは不要です。
- 置き場所は `assets/images/` 以下。ファイル名・座標は `js/config/skin.js` で一元管理しています（変える時はここだけ）。
- 画像を置いたら `js/config/game.js` の `USE_IMAGE_ASSETS` を `true` に（プレビューは URL に `?images=1` でも可）。
- 置いていない素材はプレースホルダー表示になるため、**少しずつ差し替えて確認できます**。
- 1080幅は一般的なAndroid（幅412px × 2.6倍密度）の実解像度とほぼ同じなので、下表のサイズで十分くっきり表示されます。

## 優先度

1. **最優先**: `cabinet_bg`、図柄8種、`reel_frame`、`lucky_off/on`、`stop_*`、`lever_on_*` … これで遊べる見た目になる
2. **次**: ステータスランプ、ラインランプ、`auto_*` / `menu_*`、`lever_knob*`
3. **後で**: `bonus_panel_*`、`big_logo` / `reg_logo`、LEDスプライト、演出用素材

## 制作時の注意

- 切り抜き素材は**キャンバスサイズを上表どおり**にし、中身は中央寄せ（余白は透明）。サイズが違っても枠に引き伸ばして表示されるため、縦横比だけは必ず合わせる。
- on/off は**同じ構図・同じ位置**で明るさだけ変える（切替時に位置が動かないように）。
- 背景に描き込んだ部品と、パーツ画像が二重にならないよう、パーツ部分は背景では「消灯状態の台座」程度にとどめるか空けておく。
- **図柄について**: ピエロ図柄は不採用（正式デザイン画像のピエロは使わない）。図柄は 赤7・BAR・チェリー・ブドウ・ベル・リプレイ・山 の7種。
