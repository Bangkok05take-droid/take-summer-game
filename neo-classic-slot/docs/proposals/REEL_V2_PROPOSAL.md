## 1. 図柄・役の変更点

| 項目 | 現行 | v2案 |
|---|---|---|
| ピエロ図柄 | あり（内部コード S） | **廃止** |
| 山図柄 | 装飾＋リーチ目用 | **主役図柄**（花火のような山）。山小役・チャンス目・リーチ目に使用 |
| 山小役 | なし | **山-山-山**。ピエロ役の枠をそのまま引き継ぎ（**1/1024・10枚**）。成立ラインは下記の3ラインのみ |
| その他の役・内部抽選・ボーナス確率 | — | **変更なし**（BIG 1/100・REG 1/100、ブドウ・チェリー・ベル・リプレイも同じ） |

### 有効ラインと成立条件

5ライン（中段・上段・下段・右下がり・右上がり）は変更なし。

| 役 | 成立条件 |
|---|---|
| チェリー | 左チェリー＋**同じライン上の中チェリー**（右不問）。左下段チェリーなら「中下段（下段ライン）」か「中中段（右上がり）」が対応位置 |
| 山小役 | 山-山-山。ただし**中リール中段を通る3ライン（中段・右下がり・右上がり）のみ**。→ 山小役では中の山は必ず中段に止まる |

山小役のラインを絞ったことで「**中の山は通常中段、上段・下段に滑ったら特別**」がルールとして明確になります（中の山が上段・下段の時は山小役になり得ない）。

## 3. 左リールBAR狙いの停止形

BAR狙い＝押した瞬間にBARが上段〜中段付近にある状態。

```
            通常（ハズレ・小役）   チェリー成立        山小役             大滑り（ボーナス）
  上段        リプレイ             ブドウ              山 ←滑って出現      ブドウ
  中段        ブドウ               BAR                リプレイ            赤7
  下段        BAR ←基本形          チェリー ←チャンス  ブドウ              山 ←下段まで大滑り
```

| 内部 | 左リールの停止（BAR狙い・検証値） |
|---|---|
| ハズレ・ブドウ・リプレイ・ベル | **BAR下段 100%**。チェリー・山は窓に出ない |
| チェリー | チェリー**下段**に停止 100%（→中で対応チェリーを引き込み 100%入賞） |
| 山小役 | 山が**上段**に滑って出現 100% |
| ボーナス（出目モード次第） | チェリー中段／下段、山中段／**下段（大滑り）** など |

- 左にチェリー・山が見えるのは **その小役かボーナスの時だけ**（＝チャンス目）。ハズレ等では総当たりで0件。
- **左中段チェリー**はチェリー成立では止まらない形（ボーナス時のみ）。必ず中で外れて2確になる隠れ確定形です。

## 4. リーチ目・チャンス目一覧

### チャンス目（確定ではない）

| 名称 | 条件 | 停止を許す内部 |
|---|---|---|
| 左チェリー出現 | 左リール窓にチェリー | チェリー or ボーナス |
| 左山出現 | 左リール窓に山 | 山小役 or ボーナス |

### 確定リーチ目（ボーナス非成立では絶対に停止しない）

| 名称 | 成立条件（左／中／右の行） | 確定 | 確定する停止 |
|---|---|---|---|
| **チェリー外れ** | 左にチェリー、かつチェリー非入賞 | BIG/REG | 順押しで**第2停止**（ペカリ） |
| **チェリー外れ＋中段7**（代表形） | 上記＋**中リール中段に赤7** | BIG/REG | 順押しで第2停止 |
| **挟み打ち山否定** | 左→右→中の順、**左山下段**、**右上段が山でない**（＝右上がりラインの山小役が否定） | BIG/REG | **第2停止**（右）でペカリ |
| **山V字** | 左上段 山・**中下段 山**・右上段 山 | BIG/REG | 挟み打ちなら第3停止（中） |
| **大山**（中山上段） | 左下段 山・**中上段 山**・右下段 山 | **BIGのみ** | 第3停止 |
| **谷**（中山下段） | 左中段 山・**中下段 山**・右中段 山 | **BIGのみ** | 第3停止 |
| 小山 | 左中段 山・中上段 山・右中段 山 | BIG/REG（REG寄り） | 第3停止 |
| BAR一直線 | BAR-BAR-BAR が有効ライン上 | BIG/REG | 第3停止 |
| 逆押し右中段7 | 右第1停止で右中段に赤7 | BIG/REG | 第1停止 |

```
   山V字（ボーナス確定）     大山＝中山上段（BIG確定）   谷＝中山下段（BIG確定）
   左   中   右              左   中   右                 左   中   右
   山   ・   山              ・   山   ・                 ・   ・   ・
   ・   ・   ・              ・   ・   ・                 山   ・   山
   ・   山   ・              山   ・   山                 ・   山   ・
```

- 中の山が上段・下段に止まっても、**左右の形が揃わなければ確定ではありません**（ご指定どおり、組み合わせで判定）。
- 中の山が下段で、左右が**上段**なら V字（ボーナス）、左右が**中段**なら谷（BIG）。中上段で、左右**下段**なら大山（BIG）、左右**中段**なら小山（REG寄り）。
- 中段に赤7が止まらないチェリー外れも、出現自体がボーナス時のみなので確定扱いです（後述の制約参照）。

## 6. 決めていただきたい点

1. **山小役の確率・払い出し**: 案はピエロの枠をそのまま引き継ぎ **1/1024・10枚**。この確率だと「左山出現」はほぼボーナス寄りのチャンス目になります。山小役をもっと頻繁にしたい場合は確率の指定をお願いします（ハズレ枠から割り当て、機械割が変わります）。
2. **チェリー外れ時の中段7の割合（現状約半分）**: 中リールの赤7が2個のため、外れ時に中段7まで見せられるのは約48%。残りは「チェリー外れ（7なし）」で、これも確定です。中段7の割合を上げたい場合は中リールの赤7を3個に増やす案があります（配列を再調整）。
3. **小山（REG寄り）**: 以前の仕様から残しています。「中の山上段はBIG確定」と紛らわしければ廃止できます。
4. **BAR一直線・逆押し右中段7**: 以前の仕様から継続。不要なら廃止できます。
