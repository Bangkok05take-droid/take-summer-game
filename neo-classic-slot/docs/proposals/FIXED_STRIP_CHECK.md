## 総当たり検証（1〜3枚掛け・6押し順・持ち越し中、171ケース）: OK 152 / NG 19

| 問題 | 結果 | 原因 |
|---|---|---|
| リプレイ | **入賞0%**（全押し方で揃わない） | 中リールにリプレイが1個も無い（左2・中0・右1） |
| ブドウ | 取りこぼし 約17%（入賞83.4%） | 揃えられる位置が足りない |
| 左BAR(4番)押し | ハズレ・ブドウ・ベル・リプレイで止まれる位置が無い（1764通り） | 4〜8番が BAR・チェリー・ブドウ・サイ・山 で、どこに止めても左窓にチェリーか山が見える（承認済み「左チェリー出現／左山出現＝チェリー・山・ボーナスのみ」と矛盾）。固定位置どうしの問題で、他の図柄では直せない |
| BIG・REG | 揃いやすさ 約2〜5%（現行は約15〜22%） | 中・右の赤7が1個ずつ、右BARが1個 |
| 持ち越し中の目押し保証 | OK（324/324） | |
