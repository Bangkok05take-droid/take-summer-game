# 逆押し出目法則（ゴーゴージャグラー3風）実現可能性の検証

ステータス: **検証済み・未実装**（仕様の確定待ち）。ゲーム本体は変更していない。

## 指定された停止形（右第1停止・MAX BET）

| 形 | 右窓（上/中/下） | 許す内部 |
|---|---|---|
| ① | ブドウ / 赤7 / BAR | BIG・REG・ブドウ（・チェリー） |
| ② | 赤7 / BAR / 山 | BIG・REG・山 |
| ③ | BAR上段 | REG確定 |
| 2確 | ①②のあと中リール中段に赤7・BAR | BIG・REG |
| 2確（順押し） | 左チェリー＋中段 赤7・BAR（チェリー非入賞） | BIG・REG |

## 検証結果

1. **①②③は実現可能**。ただし右リール配列の変更が必要。
   - 1組の「山・BAR・赤7・ブドウ」から①②③を全部作ると、③・②・①の禁止形が3コマ連続し、
     BAR狙いのビタ押しでリプレイの逃げ場が2コマしか残らず、**リプレイの取りこぼし**が出る（局所探索でも解なし）。
   - **①と②を別のBAR・赤7の組で作る**と解決。候補配列（番号0→20、図柄数は現行と同じ）:
     `R B 7 G M R G M B 7 R G 7 G L R M G R G M`
     - ①=停止位置2（上ブドウ・中7・下BAR）、②=停止位置8（上7・中BAR・下山）、③=停止位置0と7
     - 総当たり検証（1〜3枚掛け・全押し順・持ち越し中含む165ケース）すべてOK、ブドウ・リプレイ取りこぼし無し、持ち越し中の目押し保証100%
2. **チェリーは①に入れられない**。逆押しでは左リールが最後で、チェリーを必ず取れない（約66%）。
   ①のあとチェリーを取りこぼすと「右中段7・ブドウ非入賞」のボーナス確定目になってしまうため、
   制御が①を選べない（許可しても実際には出ない）。→ ①は「BIG・REG・ブドウ」。
3. **既存リーチ目「逆押し右上段7＝REG確定」と②が矛盾**（②は上段7でBIG・山もあり）。→ 廃止が必要。
4. 2組目の赤7（上リプレイ・下BAR）が中段に止まると、ブドウが無いので**第1停止でボーナス確定**になる（新しい1確目）。
5. 前回指示の「赤7中段=ブドウ/ボーナス、赤7下段=ハズレ/BIG、赤7枠下=リプレイ/チェリー、ベル、山」は
   押し位置ベースの法則で、今回の形ベースの法則（①②③）と一部重なる（例: チェリーの扱い）。どちらを正とするか確定が必要。
