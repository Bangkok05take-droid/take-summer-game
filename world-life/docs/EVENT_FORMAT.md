# 本番イベントデータの形式（ChatGPT本部向け）

本部がこの形式でイベントを作成すれば、Claude Code が `src/data/events/` に取り込みます。
取り込み時に自動テストで不備（ID重複、空の本文、選べる選択肢がない等）を検出します。

## 1件の書き方

```
id: ev_romance_03            … 一意のID（英数字と_）
種別: romance               … social / romance / fate / vip / business / scandal / party / bigfate
タイトル: 月夜のクルーズ
本文: チャオプラヤー川のディナークルーズに誘われた。
人物: muse                  … 登場人物ID（省略可）
出やすさ: 1                 … 省略時1。2なら2倍出やすい。0なら出ない
発生ターン: 5〜20           … 省略時は全ターン

選択肢1: 一緒に乗る（必要資金 $40,000）
  AIの選びやすさ: 2         … 省略時1
  結果A（重み3）: 最高の夜になった。 → 所持金 -40000 / 幸福度 +12
  結果B（重み1）: 船酔いしてしまった…。 → 所持金 -40000 / 幸福度 -3
選択肢2: 断る
  結果（重み1）: また今度。 → 幸福度 -2
```

## 効果に使える項目

| 項目 | 内容 |
|---|---|
| 所持金 | 増減額（$）。足りない分は自動で負債になる |
| 負債 | 増減額（$）。借入イベントなど |
| 名声 / 人脈 / 幸福度 | 増減値（0〜100に自動で収まる） |

## ルール（自動処理）

- 必要資金のある選択肢は、所持金が足りないと選べない（無条件で選べる選択肢を最低1つ入れること）
- 負債が上限（総物件評価額の50% + $200,000）を超えると「支払い不能」として自動清算する
  - 現金で返済 → 物件を安い順に強制売却（購入価格の70%）→ それでも超過なら債務整理（超過分免除、名声-10・幸福度-10）
- 1つのマスでは、その種別のイベントから「出やすさ」と「発生ターン」に従って抽選する

## 登場人物（仮）

socialite（社交界の華）, investor（投資家）, muse（運命の人）, oracle（占い師）, host（クラブの支配人）, celebrity（有名人）, reporter（記者）, tycoon（大富豪）, dealer（伝説のディーラー）

新しい人物は ID と表示名を指定すれば追加できます（画像はビジュアル制作室が `characters/cutin/<ID>.webp` で提供）。
