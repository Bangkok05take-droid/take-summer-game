# 指令 No.005 対応記録（ゲーム性強化・チュートリアル）

## 実装
1. 体験型チュートリアル（8段階・案内役コンシェルジュ）
   - 初回の「新しく始める」で自動開始。タイトルの「遊び方（チュートリアル）」で何度でも再確認できる。スキップ可
   - 最初のサイコロは1に固定し、必ず物件購入を体験させる。その後ライバルの番、収益、イベント、ガイドの順に案内
2. 💡今おすすめの行動／🎯次の目標（マップ上部）
   - サイコロ前：空き物件・ライバル物件に止まれる目を表示
   - 分岐：各ルートの止まり先を表示し、おすすめを提示
   - 購入：毎ターンの収益、残りターンでの見込み額、元が取れるまでのターン数
   - 目標：物件を手に入れる／あと1件でエリア独占／1位との点差
3. 購入時の「物件GET！」演出（収益と見込み、独占バッジ）、買収時の「買収成功！」
4. AIの個性（レオン＝攻めの投資家、ミラ＝社交界の華、カイ＝天性の勝負師）とセリフ
   - **買収**：他人の物件に止まると、購入価格の1.5倍（相手がエリア独占中なら2倍）で買い取れる。代金は元の所有者へ
5. テンポ：AIの手番の演出を短縮（サイコロ0.52秒、1マス0.15秒）。人間の手番はじっくり見せる
6. 資産順位：HUDに順位・変動（▲▼）・純資産の推移グラフ。ターン開始時に順位変動を通知
7. 効果音を追加：買収、順位アップ・ダウン、AIのセリフ（ミュート切替あり）

## 競売（オークション）の基礎設計案（本部確認待ち・未実装）
- 発生条件：空き物件に止まったプレイヤーが購入を見送ったとき
- 参加者：全員（見送ったプレイヤーも可）。開始価格は購入価格の70%
- 進め方：テンポ維持のため1回限りの封印入札。各自が「見送り／+10%／+30%／+50%」から選び、最高額の人が落札
- AI：個性ごとに上限額を設定（レオン高め、ミラ低め、カイはランダム幅大）
- 所要時間の目安：1回あたり5秒以内

## 確認結果
- 自動テスト 74件合格
- スマホ表示（iPhone 13 相当）でチュートリアル通し、20ターン完走、エラーなし
