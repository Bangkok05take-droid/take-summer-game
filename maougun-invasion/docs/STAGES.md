# 人間軍と初期ステージの敵構成（第1版・仕様検討用）

数値はすべて**仮**です。単位は `UNITS.md` の「0. 数値の単位と前提」と同じです。

## 1. 人間軍のユニット

人間軍は「きらきらした正義の側」。明るい色の鎧・旗・笑顔で、魔王軍の紫・黒と画面の上で見分けやすくします。
絵は新規（96×96 ×4コマ：歩き2・攻撃準備・攻撃発動、右向き）。

## 2. 第1章「はじまりの村を侵略せよ」

舞台：たけたちの村のまわり（既存ゲームの村の雰囲気を、横スクロールの背景として新規に描く）。

- `t秒〜 間隔` … その時刻から決まった間隔でくり返し出す（「最大」は同時に戦場にいる数の上限）
- `拠点HP◯%` … 人間軍の拠点のHPがその割合を下回ったときに1回出す

### 勝ち負けとやり直し
- 拠点を壊せば勝ち。封印の祠（HP：第1章は 5,000）を壊されたら負け。
- 負けても、その戦いで倒した敵の魔石の半分はもらえる（くり返し挑みやすく）。
- 星の条件（案）：勝つ／祠のHP 50% 以上で勝つ／3分以内に勝つ。
