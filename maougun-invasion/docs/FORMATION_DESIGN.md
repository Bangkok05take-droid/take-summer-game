## 2. 既存仕様との矛盾・バランス上の問題

1. **恒久強化で「初期の魔力炉でも幹部を出せる」ようになる**：最大魔力は 1000 ＋魔力の器（最大+1000）＋大魔王Lv（+60/Lv）。強化を進めると、魔力炉 Lv1 のまま 1500 に届く。
   → 案：幹部ごとに「必要な魔力炉Lv」を持たせる（例：突進は炉Lv3以上）。恒久成長で数値がふくらんでも、「戦闘中に炉を上げてから幹部」という流れは守られる。
2. **大魔王のレベルがクリア数そのもの**：第1章は最大 Lv6。後半の「6+2」を解放するには第2章以降のステージが必要。
3. **幹部が「突進」1種しかない**：幹部2枠は、2種類目の幹部（能力と絵）ができるまで意味がない。
4. **呪文の扱い**：仕様では「魔王の力」で呪文を解放するが、現状は最初から使える（オープニングの説明とテストも前提にしている）。
5. **編成上限5枠と現在の出撃**：今は解放した全員が出撃する。5枠になると、1-2（解放6種）から選ぶ必要が出る。チュートリアルの1-1（4種）は影響なし。
6. **名前の重複**：幹部の内部キー `mist`（霧）と、側近「ミスト」が紛らわしい。名前はストーリー側で確定してもらう。

## 3. 推奨案

### 3-1. 大魔王の成長（3系統）
- **大魔王Lv**：今の「クリア数＋1」を続ける。各章のボスステージで +1 のボーナスを足す。
- **① 支配力（編成枠・レベルで自動解放）**

  | 編成枠 | 解放条件（案） | 時期 |
  |---|---|---|
  | 通常5＋幹部1 | 最初から（幹部枠は幹部を持つまで鍵表示） | 1-1〜 |
  | 通常6＋幹部1 | 大魔王 Lv4（1-3 クリア） | 第1章後半 |
  | 通常6＋幹部2 | 大魔王 Lv9（第2章の中盤ボス） | 第2章 |

- **② 魔力（魔界石で強化。今の「魔力の器・魔力の泉」を移す）**：最大魔力・回復。戦闘開始時の数値に反映する。戦闘中の魔力炉（その戦闘だけ有効）とは画面も名前も分ける。
- **③ 魔王の力（魔界石）**：呪文は最初から使えるまま。強化（威力 +15%／Lv、ため時間 −2秒／Lv、5段）と、第2章以降の新しい呪文・支援をここで解放する。「召喚の陣（再召喚短縮）」もここへ移す。

### 3-2. 幹部召喚
| 項目 | 案 |
|---|---|
| 同時出撃 | 戦場の幹部は種類を問わず1体まで。出撃中は全幹部カードを「出撃中」で押せなくする |
| 召喚条件 | 魔力（費用）が足りること＋**魔力炉が必要Lv以上**であること |
| 突進 | 費用1500・炉Lv3以上・HP7000（現状のまま） |
| 2体目以降の幹部 | 費用1400〜1800・炉Lv3〜4 |
| 再召喚 | 撃破されてからその幹部は60秒。**ほかの幹部も20秒は出せない**（交代の連打を防ぐ） |
| 目安 | 1-5相当なら、炉Lv3（累計400魔力）まで約40〜60秒。1戦（3〜5分）で幹部は2〜3回出せる |

### 3-3. 偵察 → 編成 → 出撃
1. ステージを選ぶ
2. 偵察報告：側近が短く報告する（2〜3行・スキップ可・毎回表示、2回目以降は1行に短縮）。既存の「前の会話」を流用する
3. 敵軍情報：出現表から兵種を自動で集め、カードで表示する（名前・役割・注意点。例：僧侶「回復する」、盾兵「ノックバックしない」、勇者「後半に登場」）
4. 編成画面：通常枠と幹部枠を分けて表示する。未解放の枠は鍵表示。「敵軍情報」ボタンで3.をいつでも見られる。編成は保存して次のステージにも引き継ぐ
5. 出撃

### 3-4. 実装の範囲（承認後）
- セーブ：`version 2`（編成・成長を追加。今のセーブから自動で移行する）
- 戦闘：`deck` を編成から作る／幹部の同時1体制限・必要炉Lv・共通の再召喚待ちを追加。今の数値と勝敗ロジックはそのまま
- 画面：偵察・編成・成長（3系統）を新しく作る。HUD のカードは最大8枚（通常6＋幹部2）
- テスト：既存のテストを保ち、編成・枠解放・幹部制限・セーブ移行のテストを追加する
