【魔王軍の世界侵略｜モンスター進化 企画・デザイン依頼のまとめ】

■ いまゲームに入っている仕組み（決まっていること）
- 進化は3段階：基本形 → 上位（第2形態）→ 最上位（第3形態）
- 上位進化は 6-3「古代王の復活」の初回クリア（大魔王の魔力回復イベント）で解放
- 最上位進化は 8-4「魔法都市の最終決戦」の初回クリア（魔王軍の究極進化イベント）で解放
- 進化は「強化」画面で行う。進化すると同じ枠のまま、見た目・名前・能力が変わる（編成枠は増えない）
- 分岐進化ができる（例：木槌小鬼は最上位で「一撃型」と「連投型」に分かれる）。一度選んだら戻せない（今の仕様）
- 戦闘中の動きはゲーム側で付けるので、絵は静止画1枚でよい
- 仮の条件：モンスターLv5以上＋魔界石（上位 700／最上位 900）

■ 進化の対象（通常モンスター8体）
| 今の名前 | 役割 | 攻撃 | 進化の案 |
|---|---|---|---|
| グミ | 量産型（安い・弱い・数で押す） | 近接 | 未定 |
| 闇の騎士 | 前衛 | 近接 | 未定 |
| 岩男 | 高HPタンク | 近接 | 未定 |
| 弓ゴブリン | 遠距離 | 弓（放物線） | 未定 |
| こうもり | 高速・飛行 | 近接 | 未定 |
| 魔法使い | 範囲攻撃 | 火の玉（中距離） | 未定 |
| 森のお化け | 回復支援 | 中距離 | 未定 |
| 木槌小鬼 | 後衛狙撃（前線を越えて後ろの敵を狙う） | 木槌を投げる | 上位1種 → 最上位2種に分岐（案のみ・絵なし） |

幹部（ワニ将軍・竜人オルド）を進化させるかどうかも未定。

■ 決めてほしいこと（企画）
1. 進化させるモンスター：8体全部か、一部だけか
2. 進化の段階：全員3段階か、2段階で終わるものも作るか
3. 分岐：どのモンスターを分岐させるか（全員1本道／一部だけ分岐／全員分岐）
4. 進化の条件：
   - モンスターのレベル（今は Lv5。最大 Lv10）
   - 魔界石の量
   - 特別な素材を使うか（例：ステージの戦利品・ボスを倒すともらえる石など）。使うなら素材の種類と入手場所
   - 進化したらレベルを1に戻すか、そのままか
   - 分岐を選び直せるか
5. 進化で何が変わるか（モンスターごと）：
   - 能力（HP・攻撃・射程・速さ・召喚コスト・再召喚時間）の上がり方
   - 新しい技・特徴（例：グミが分裂する、岩男がトゲで反撃、こうもりが急降下など）
   - 役割を変えるか（例：前衛 → 盾役、遠距離 → 範囲）
6. 名前：進化形ごとの名前（既存作品と似ない名前で）
7. 演出：進化するときの画面（光る・会話を入れる・解放画面など）
8. 幹部の進化：ワニ将軍・竜人オルドも進化させるか

■ 作らなきゃいけないデザイン（ビジュアル制作室）
- 進化形のモンスターの絵：段階 × 分岐の数だけ必要
  - 例：8体が全員「上位1種・最上位2種」なら 8 × 3 ＝ 24枚
  - 例：8体が全員1本道で3段階なら 8 × 2 ＝ 16枚
- 規格（今の魔王軍と同じ）：
  - 1体ずつの透過PNG（RGBA）、四隅は完全に透明
  - 左向き（魔王軍は右の祠から左へ進む）
  - 静止画1コマ
  - 足元の位置を基本形とそろえる。進化するほど少し大きく・豪華に
  - 武器・翼・しっぽを欠けさせない
  - manifest.csv と確認用プレビューを同梱して ZIP で納品
  - ファイル名の例：mass_2.png／mass_3a.png／mass_3b.png（基本形のキー＋段階＋分岐）
  - 基本形のキー：mass（グミ）・vanguard（闇の騎士）・tank（岩男）・ranged（弓ゴブリン）・fast（こうもり）・area（魔法使い）・healer（森のお化け）・mallet（木槌小鬼）
- 必要なら：進化形の攻撃エフェクト（新しい技がある場合）、召喚カード用アイコン（なくても戦闘の絵から自動で作る）
- 必要なら：進化の演出用の素材（光・魔法陣など）

■ 守ってほしいこと
- 基本形のデザインの雰囲気（色・特徴）を引き継ぐ
- 既存のゲーム・漫画・アニメのキャラクターや名前に似せない
- 第8章までに最上位が解放されるので、終盤（第9〜10章）の敵に勝てる強さの目安を意識する（能力値の調整は Claude Code が行う）
