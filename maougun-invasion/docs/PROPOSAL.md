# 新ゲームの基本構成（提案）

## 1. ゲームの形

### 1戦の流れ
```
[封印の祠（自陣・右端）]  ←── 戦場（横に長い1本道、画面の約3〜4倍）──→  [人間軍の拠点（左端）]
       魔物が左へ進軍 ─────────────▶            ◀───────────── 人間軍が右へ進軍
```
- 魔力は時間でたまる（上限あり）。下の召喚ボタン（最大10枠＝5×2段）で魔物を出す。各ボタンに必要魔力と再召喚までの待ち時間。
- 魔物・人間はそれぞれ自動で前進し、射程に敵が入ると止まって攻撃する。
- **魔力炉の強化**：魔力を払うと、魔力のたまる速さと上限がその戦い中だけ上がる（にゃんこの「働きネコ」に当たる）。
- **魔王の呪文**：時間でたまる必殺。戦場の先頭付近の人間を一掃・ノックバック（にゃんこの「ネコ砲」に当たる）。
- 拠点のHPが0で勝ち、祠のHPが0で負け。ボス戦では、拠点が一定まで削れると人間軍の勇者が出てくる。

### 戦闘の決まり（初期案）
| 項目 | 内容 |
|---|---|
| ユニットの数値 | HP・攻撃力・射程・移動速度・攻撃間隔（準備→発動→戻り）・ノックバック回数・召喚コスト・再召喚時間 |
| 攻撃の種類 | 単体／範囲（射程内全員）／遠距離（弾が飛ぶ）／貫通（一直線） |
| ノックバック | 最大HPを決まった回数に割った量を受けるたびに後ろへはじかれる（大技の見せ場） |
| 特性 | 飛行・硬い（被ダメ減）・回復・毒・足止め・自爆・分身 など。既存ゲームの敵の行動をそのまま性格づけに使う |
| 相性 | 人間軍に属性（騎士・弓兵・僧侶・魔法使い・勇者）。魔物の特性で「よく効く・打たれ強い」 |
| 判定 | 位置は1次元（x 座標のみ）。描画と切り離した固定時間ステップ（1/30秒）で、同じ乱数シードなら同じ結果 |

### 戦いの外（成長）
- **世界侵略マップ**：章ごとに地方を順に攻める（村 → 港町 → 砦 → 王都 → 聖域 など）。各地方3〜5ステージ。
- 勝つと「魔石」（通貨）と、まれに新しい魔物のたまごを得る。
- **魔王城**：魔石で魔物のレベル上げ、新しい魔物の解放、魔力炉・祠の基本性能の強化、編成（召喚ボタンの並び）。
- セーブは localStorage（版番号つき・旧データの移行を最初から用意）。

## 2. 画面（スマホ優先）

- **横持ち**を基本（論理解像度 960×540、16:9。それ以外の比率は上下か左右に余白）。縦持ちのときは「横にしてね」の案内を出す。
- 上：祠と拠点のHP、魔力（数字とゲージ）、一時停止・倍速。
- 中：戦場。ドラッグ／スワイプで左右にスクロール。自動で前線を追う「追従」切り替え。
- 下：召喚ボタン（大きく、指で押しやすい）、魔力炉ボタン（左下）、魔王の呪文ボタン（右下）。
- 演出の「控えめ」設定（画面の揺れ・強い点滅をおさえる）は既存ゲームと同じ考え方で最初から入れる。

### ビジュアル（かわいいダークファンタジー）
- 2〜3頭身のドット絵（既存素材と同じ画風）。紫・深い青・赤の差し色、魔物はコミカルに、人間軍はきらきらした「正義の側」。
- 背景は横長の多層スクロール（遠景の山・中景の村や城・手前の地面）。
- 魔物の描画は最近傍の整数倍（ドット絵のまま）。小型は既存シートの1コマ96×96を縮小せずに使い、画面の倍率で調整する。

## 3. 技術構成

| 項目 | 案 | 理由 |
|---|---|---|
| 言語・形式 | 素の HTML / CSS / JavaScript（ES modules）、**ビルド不要** | 既存ゲームと同じ形で、GitHub Pages にそのまま置ける。素材の流用もしやすい |
| 描画 | Canvas 2D（`imageSmoothingEnabled = false`） | ユニット数十体なら十分速い。ドット絵向き |
| ループ | 固定ステップのロジック（30Hz）＋ requestAnimationFrame の描画（補間） | 端末の速さで結果が変わらない。テストしやすい |
| 構造 | `js/core/`（ロジック、DOM 無し）／`js/render/`／`js/ui/`／`js/data/` | 既存の「data.js・game.js・render.js・ui.js を分ける」構成を踏襲 |
| 素材の一覧 | `js/data/assets.js` に「キー → ファイル・コマ割り・足元・向き」 | 既存の `assets.js` と同じ。差し替え・名前変更が1か所で済む |
| 音 | 既存の `audio.js`・`music.js` をコピーして改造（WebAudio） | 外部ライブラリ不要 |
| テスト | `node tests/battle.test.js`（ロジックだけ、シード固定）・Playwright でスマホ画面の確認 | 既存ゲームと同じやり方 |
| 公開 | GitHub Pages（相対パスのみ、`.nojekyll`） | |

## 4. 素材の取り込み方

1. `tools/import-assets.sh`（作成予定）で、既存リポジトリの**決まったコミット**から、一覧に書いたファイルだけをコピーする（既存側には書き込まない）。
2. コピーした各ファイルの「元のパス・コミット・SHA256・新しいパス・加工の有無」を `docs/ASSET_SOURCES.md` に自動で記録する。
3. 名前は新ゲーム用に付け直す（例：`assets/units/slime.png` ではなく役割と新しい名前で）。
4. `reference/`・ムービー・ダンジョンのタイル・タイトル絵はコピーしない。

### 足りない素材（新しく必要）
| 素材 | 寸法の目安 | 備考 |
|---|---|---|
| 封印の祠（自陣） | 約160×200 | 被弾で段階的に壊れる3段階があると良い |
| 人間軍の拠点（村の見張り台・砦・城門・王城） | 約160×200 | 地方ごと |
| 人間軍の兵士（剣士・弓兵・僧侶・魔法使い・騎士） | 96×96 ×4コマ（既存の敵シートと同じ形） | 歩き2・攻撃準備・攻撃発動。右向き |
| 横スクロール背景（地方ごと） | 横1920〜2880×縦540、2〜3層 | |
| 魔王・魔物（オリジナル案にする場合） | 96×96 ×4コマ | 下の「決めてほしいこと」参照 |
| 召喚ボタンのアイコン | 64×64 | 既存シートの待機コマから自動で作れる |

## 6. 決定事項（2026-11-23）
1. **キャラクター**：既存の敵・ボスは戦闘能力と役割だけを参考にし、名前・外見・技名はオリジナルの魔王軍を制作する。既存の敵・ボスの絵は使わない。案は [UNITS.md](UNITS.md)。
2. **幹部（ボス）**：強力なレア召喚ユニット。同じ種類は同時に1体まで。
3. **人間軍**：たけ・サイを人間軍の勇者として登場させる。案は [STAGES.md](STAGES.md)。
4. **画面**：スマホ横持ち 16:9。
5. **保存場所**：`take-summer-game/maougun-invasion/` で継続。
6. **ビジュアル**：かわいいダークファンタジー。
7. 本格実装は仕様確定後に開始。既存ゲームのコード・素材は変更しない。
