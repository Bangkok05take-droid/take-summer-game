# 開発方針（統合指示書 Ver.2.0 ＋ 編成修正を反映・2026-11-23）

## 1. コンセプト

- プレイヤーは大魔王率いる魔王軍の指揮官。封印の祠から魔物を次々と召喚し、人間軍の拠点を攻略して世界を侵略する。
- 参考にするゲームシステムは『にゃんこ大戦争』（横スクロールのレーン型）。キャラクター・ビジュアル・UI・演出は独自に作る。
- **最重要：魔物を大量に召喚して敵軍を押しつぶす爽快感。** 複雑な操作より、テンポのよい召喚と戦略性を優先する。

## 2. 基本仕様

| 項目 | 内容 |
|---|---|
| 端末 | スマホのブラウザ優先（横持ち 16:9）。PCブラウザにも対応 |
| 1ステージ | 約3〜5分 |
| 配置 | 左：魔王軍の封印の祠 ／ 右：人間軍の拠点 |
| 進軍 | 魔物は左から右へ、人間軍は右から左へ自動で進む。射程内に敵が入ると止まって自動で攻撃 |
| 勝敗 | 敵拠点のHPが0で勝ち、祠のHPが0で負け |
| 速度 | 通常・2倍速 |
| 召喚ボタン | 画面下。最終的に最大10枠、試作は4枠 |

### 魔力

| 項目 | 値（仮） |
|---|---|
| 開始時 | 200 |
| 最大 | 1,000 |
| 回復 | 毎秒 20 |
| 魔力炉 | 1段ごとに最大 +250・回復 +6/秒（Lv8まで。費用 150・250・…・750） |
| 同時出撃上限 | 30体 |
| 倒した人間 | 魔力が少し戻る（自警団30・剣士70） |

召喚できないとき（魔力不足・再召喚待ち・出撃上限・幹部の出撃中）は、ボタンの上に理由を表示し、押すと理由をお知らせで出す。

### ユニット・幹部・大魔王

- 通常8枠・幹部5枠・大魔王（別枠）。詳細は [UNITS.md](UNITS.md)。
- 幹部：1ステージに最大2種類。同じ種類は同時に1体まで。生存中は再召喚不可。撃破の時点から再召喚のクールタイム。
- 魔王の呪文：魔王ゲージがたまると発動。試作は範囲攻撃1種類。
- 表示名・絵は `js/data/skin.js` で枠ごとに設定（既定は役割名と図形の仮の絵）。既存作品由来のキャラクター素材は非公開の検証用に限り、公開版では権利処理または独自素材に置きかえる。

### 人間軍・ステージ・世界地図

- 兵士6種、勇者たけ・サイ（ボス）。村人コイ・モッ・ワーン・ティウは会話・イベント・演出だけ。詳細は [STAGES.md](STAGES.md)。
- 第1章「はじまりの村を侵略せよ」5ステージ。1-5 で拠点HP 70% で勇者たけ、40% で勇者サイ。
- 世界侵略マップ：6エリア・30ステージ。攻略した領土が魔王軍の色に変わる。

### 育成（試作では未実装・データの形だけ用意）

- 魔界石で：魔物のHP・攻撃力、魔力最大値・魔力回復速度、召喚クールタイム、新しい魔物の解放。
- 魔物の進化・上位互換を後から追加できる形（`tier`・`evolvesTo`・`growth`、プロフィールの `level`・`form`）。
- データの形と計算は `js/data/progress.js`（`newProfile`・`resolveUnit`・`resolveMana`）。

## 3. 技術構成

| 項目 | 内容 |
|---|---|
| 形式 | 素の HTML / CSS / JavaScript（ES modules）。**ビルド不要・依存パッケージなし** |
| 描画 | Canvas 2D（戦場）＋ DOM（上下の操作部分）。論理 960×540 を画面に合わせて拡大 |
| ループ | ロジックは固定時間ステップ（1手 = 1/30秒）、描画は requestAnimationFrame で補間。倍速は「実時間あたりの手数」を増やすだけなので、結果は通常速度と同じ |
| 再現性 | シード付き乱数（`js/core/rng.js`）。操作は手のはじめに反映するキュー。同じシード＋同じ操作 → 同じ結果（テスト済み） |
| 分離 | `js/core/`（ロジック、DOM 無し）／`js/data/`（数値・見た目の設定）／`js/render/`（描画）／`js/ui/`（ボタン・表示） |
| 入力 | タッチ（pointer イベント。押した瞬間に反応）・マウス・キーボード |
| セーブ | 試作では無し。プロフィールの形と保存キー（`maougunInvasion.save`）・版番号を用意 |
| テスト | `npm test`（ロジック 19件）・`npm run e2e`（Playwright でスマホ横画面 23件）・`npm run balance`（ボットでテンポ確認） |

### フォルダ

```
maougun-invasion/
  index.html / css/style.css
  js/main.js              入口（戦闘・時計・描画・画面をつなぐ）
  js/core/battle.js       戦闘ロジック（進軍・射程・攻撃・ノックバック・撃破・魔力・召喚・幹部・呪文・敵の出撃・勝敗）
  js/core/clock.js        固定ステップの時計（倍速・一時停止）
  js/core/rng.js          シード付き乱数
  js/data/units.js        魔王軍（通常8枠・幹部5枠・大魔王）
  js/data/humans.js       人間軍（兵士6種・勇者2人）
  js/data/stages.js       共通設定（上限・魔力炉・呪文）とステージ
  js/data/progress.js     育成・セーブのデータ構造
  js/data/skin.js         表示名・色・絵の登録
  js/render/renderer.js   戦場・祠・拠点・演出・小さな地図
  js/render/shapes.js     図形の仮の絵（役割ごとのシルエット）
  js/ui/hud.js            上下の表示と召喚ボタン
  assets/                 絵・音（未着）
  tests/                  テスト・ボット・確認用サーバー
```

## 4. 素材

- キャラクター・背景・追加アニメーションの制作は ChatGPT 側。寸法・向き・コマ数・形式・ファイル名は [ART_SPEC.md](ART_SPEC.md)。
- 素材が届くまでは図形の仮の絵で進める（届いた枠から `skin.js` に登録すれば差し替わる。読めなければ仮の絵に戻る）。
- 既存『たけとサイの大冒険』の素材は、権利関係を確かめて使ってよいもの（自作のたけ・サイ・村人・村の素材・汎用の演出・BGM）だけをコピーする。既存リポジトリは変更しない。
