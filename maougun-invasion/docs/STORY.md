# 第1章のストーリーと演出

本文は `js/data/story.js`（会話・戦利品）。話し手の表示名は `js/data/skin.js` の `speakers`。

## あらすじ
マスター・ヤナイたちに肉体と魔力を分断され、封印の祠に閉じこめられた大魔王。物語は封印から間もない時点で始まる。
大魔王は祠から出られないため、側近が偵察と調査を受け持つ。目的は、ヤナイを探し出して倒し、失った肉体と魔力を取り戻して、世界を再び支配すること。
ヤナイが昔救った村や町を順に攻め、手がかりを集めていく。

## 人物
| キー | 表示名（既定） | 性格 |
|---|---|---|
| `lord` | 大魔王 | 威厳はあるが、少しコミカルなおじいちゃん（腰が痛い、何百年も生きとる） |
| `aide` | 側近 | 冷静でまじめな側近。偵察・調査・報告と、戦い方の助言 |
| `tiw` `mot` `waan` `koi` | 村人 | 人間側のNPC。ステージ前の村の様子で登場（戦闘はしない） |
| `take` `sai` | 勇者たけ・勇者サイ | ヤナイの弟子。1-5 で登場（少しシリアス） |

## 演出の流れ
1. オープニング（祠の中）：大魔王と側近の会話 → 側近が最初の村を偵察 → 大魔王が侵略を命令（遊び方の説明もここで）
2. 1-1 の戦闘
3. 勝利後：側近が手がかりと戦利品を報告 → 戦利品の画面（手がかり・魔界石・大魔王の魔力の回復）→ 新しい魔物の解放
4. ステージ選択（強化）→ 次のステージ前：側近の偵察報告 → 村の様子 → 大魔王の命令 → 戦闘

## 手がかり（戦利品）
| ステージ | 手がかり |
|---|---|
| 1-1 | ヤナイの古い地図 |
| 1-2 | ヤナイあての手紙（「小川の橋の修理、ありがとう」） |
| 1-3 | ヤナイの紋章のかけら |
| 1-4 | 鍛冶屋の帳簿（「ヤナイの弟子、たけとサイの剣と盾」） |
| 1-5 | 勇者の言い残し（「師匠は東の港町にいる」）→ 第2章へ |

会話は短く、タップで送り、右上の「スキップ」でいつでも飛ばせる（PC：Enter で送り、Esc でスキップ）。

# 全体のストーリー（2026-11-25 シナリオ制作室・ユーザー承認）

## 基本方針
- オープニング・第1章・第2章の実装済みの台詞は変えない。第1章・第3章は3ステージ。
- 勇者たけ・勇者サイ・マスター・ヤナイ本人は最終章まで登場しない。大魔王は最終章まで戦闘ユニットにしない。
- 大魔王とヴェイルのコミカルな掛け合いを保つ。ゲーム内では商用公開用の名前を使う。

## 第3章「地方王国の城を攻略せよ」の実装
- 台詞は `js/data/story.js` の `before['3-1'〜'3-3']`・`after['3-1'〜'3-3']`。人間側の台詞（王国兵・王国騎士・国王）も台本の位置に入れてあり、`stages.js` の `talk`（自動の差し込み）は使わない。
- 台本の「――戦闘開始。」「――ボス戦開始。」は戦闘が始まる所（画面には出さない）。「――第3章クリア。」と次回への伏線は、3-3 の勝利後の会話の最後に地の文で出す。
- 表情（face）は表示の演出として付けた（台詞は変えていない）。
- 敵編成・ボス（国王）の能力・報酬は仮。王国騎士・国王の絵は届くまで盾兵の絵を大きくして代用。手がかり（戦利品）は未設定なので、魔界石だけを表示する。
