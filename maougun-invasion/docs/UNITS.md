# 魔王軍ユニット（第1章プレイアブル版・2026-11-23）

数値はすべて**仮**で、正は `js/data/units.js`（資料より新しい場合はコードが正）。単位：射程・移動＝論理ドット（画面幅960）、時間＝秒。
魔物は**右の祠から左へ**進みます。

## 0. 名前と絵の扱い

- ゲームはユニットを**役割の枠**（キー：`mass`・`vanguard`…）で扱います。数値・ステージ・セーブ・解放はこのキーで参照します。
- 画面に出す**表示名・絵・会話の顔は `js/data/skin.js` だけ**で決まります。既定は役割名（「量産型」「前衛」…）と、図形の仮の絵です。
- 枠ごとの名前と見た目は、プロジェクトの持ち主側で決めて `skin.js` と `assets/` に入れる運用です。既存作品由来のキャラクター素材は非公開の検証用に限り、公開版では権利処理または独自素材に置きかえる前提です。
- 絵の仕様は [ART_SPEC.md](ART_SPEC.md)。

### 上位互換・進化（将来）

- 各枠に `tier`（段階）・`evolvesTo`（進化先のキー）・`growth`（成長率）。進化形は同じ表に別キー（例：`mass_2`）で足し、基本形の `evolvesTo` に書く。
- セーブはプロフィールの `units[key].form`（進化段階）で切り替える（`js/data/progress.js` の `resolveUnit`）。編成・解放は元のキーのまま。

## 3. 大魔王（別枠）と魔王の呪文

- 大魔王は祠から魔王軍を指揮する（召喚カードには並ばない）。会話では「大魔王」（`skin.js` の `speakers.lord`）。
- **魔王の呪文**：35秒でたまる。右下の大きなボタンが光ったら発動。**人間がいちばん密集している地点**を中心に半径170の全員へ 320 ダメージと吹き飛ばし（勇者は3人分として数え、優先して狙う）。
- **第1章の成長**：ステージを初めて制圧するたびに「封印がゆるむ」→ 最大魔力 +60・魔力回復 +1.5/秒（大魔王の魔力 Lv）。
- 真の姿（`lordAwakened`）は最終章の特別ユニットの構想。
