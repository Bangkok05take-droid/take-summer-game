# 魔王軍ユニット案（第1版・仕様検討用）

- 既存『たけとサイの大冒険』の敵の**戦闘能力・役割だけ**を参考にした、オリジナルの魔王軍です。名前・外見・技名は新しく作っています。
- 「参考」の列は設計の出どころを示すためのもので、ゲームの画面や素材には使いません（既存の絵も仮の絵としても使いません）。
- 数値はすべて**仮**です。調整は試作のあとで行います。

## 0. 数値の単位と前提

| 項目 | 単位・前提 |
|---|---|
| 画面 | 論理解像度 960×540（横持ち16:9）。戦場の横幅は第1章で 2,400（約2.5画面） |
| 射程・位置 | 横方向のドット（論理座標）。近接はおおむね 20〜40 |
| 移動速度 | ドット/秒（量産型 40 が基準） |
| 攻撃間隔 | 秒（準備→発動→戻りを含む1サイクル） |
| KB | ノックバック回数（最大HPをこの回数で割った量を受けるたびに後ろへはじかれる） |
| 魔力 | 初期0、毎秒 +15（魔力炉 Lv1）、上限 600。魔力炉は Lv8 まで（毎秒 +45・上限 2,400 くらいまで） |
| 再召喚 | ボタンを押してから次に押せるまでの秒数 |

## 4. 幹部（レア召喚ユニット）

### 大魔王（祠の主）
- 名前（仮）：**大魔王 ノクス**。小さな体に大きすぎるマントと角の王冠、目が赤く光る、かわいい魔王。
- ふだんは祠にいて、**魔王の呪文**（ネコ砲に当たる必殺）を撃つ：前線の敵をまとめて焼き、はじき飛ばす（演出は火の鳥）。
- 最終章で**覚醒ノクス**（大人の姿）がレア召喚ユニットとして解放（参考：vearn → truevearn）。
  - 特技：**夜の構え**（数秒、受けた攻撃をはね返す）／**終焉の爪**（周りの敵全員に防御無視の大ダメージ）。魔力 4,000・再召喚 150秒・同時に1体まで。

## 5. 演出の素材（既存からコピーして使えるもの）

技名と結びつかない汎用の演出は、既存ゲームのファイルを**コピーして**使います。

| 既存の素材 | 新しい使い道 |
|---|---|
| `fx/slash/`（斬撃10コマ） | ほねナイト・ガーゴいしの強打、勇者たけの斬撃 |
| `fx/frey/fire_*`・`ice_*` | ヒョウカの炎の道・氷の道、ひのこ魔女の炎 |
| `fx/iona/`（大爆発6コマ） | ばくはつ岩くん、びっくり箱、くろいわトロルのたたきつけ |

固有の技と結びついた演出（`fx/truevearn/`・`fx/dragonbaran/`・`kaiser-phoenix.png`）とボス・敵の絵は使いません。
