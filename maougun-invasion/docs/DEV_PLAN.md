## 2. 再利用できるもの（そのまま使う）

- **戦闘**：`js/core/battle.js`（1ライン自動進軍・攻撃・ノックバック・射撃・範囲・回復・気絶・拠点HP・勝敗）、固定刻み時計・乱数シード
- **ユニット**：`js/data/units.js` 通常8枠（mass / vanguard / tank / ranged / fast / area / healer / special）＋幹部「突進」。表示名は `skin.js` で指定の名前に設定済み。進化用の `tier` / `evolvesTo` / `growth` 欄あり
- **人間軍**：`js/data/humans.js` 6種＋勇者たけ・勇者サイ（1-5 で拠点HP 70%／40% で登場）
- **ステージ**：`js/data/stages.js` 1-1〜1-5、敵の出現表・解放順
- **会話**：`js/data/story.js` オープニング → 偵察 → 命令 → 戦闘 → 報告・戦利品
- **強化・セーブ**：`js/data/progress.js` 魔界石・レベル強化・localStorage 保存・リセット
- **UI**：タイトル・会話・ステージ選択・強化・HUD（召喚カード・魔力炉・魔王の呪文・倍速・一時停止・ミニマップ）、PC キー操作
- **素材差し替え口**：`skin.js` / `approved.js` / `tools/accept_assets.py`。承認画像があればその部分だけ差し替わり、無ければ仮の絵のまま
- **承認済み素材**：拠点（祠・見張り小屋 各3段階）、人間軍6種、グミ、村の背景

## 4. 開発計画（既存のバトル設計は変更しない）

| 段階 | 内容 | 方針 |
|---|---|---|
| A | 受け入れテストの期待値を修正し、全テスト合格の状態を基準にする | 小さな修正のみ |
| B | 承認済み素材の組み込み（届いた順） | `accept_assets.py` → `skin.js` 登録。絵は描き直さない |
| C | 効果音・BGM の差し替え口（素材が無ければ無音） | 画像と同じ「無ければ仮」の構造 |
| D | 第1章の仕上げ（スマホ実機の操作感・テンポ・報酬バランス） | 数値は `units.js` / `stages.js` のみで調整 |
| E | 第2章の準備：世界侵略マップ・地域データ・幹部召喚・編成画面 | `stages.js` を章単位に拡張。`battle.js` の仕組みは流用 |
| F | ユニット進化（`evolvesTo` を使う）・強化項目の追加 | セーブ形式は後方互換を保つ |

各段階の終わりに `npm test` / `npm run e2e` / `npm run balance` / `npm run test:accept` を実行する。
