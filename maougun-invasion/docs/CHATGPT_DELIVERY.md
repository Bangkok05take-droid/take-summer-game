# ChatGPT への納品ルール（受け入れを速くするための指示）

以下をそのまま ChatGPT に貼り付けて使う。素材の仕様そのものは [CHATGPT_REQUEST.md](CHATGPT_REQUEST.md)。

---

【魔王軍の世界侵略｜素材の納品ルール（Claude Code からのお願い）】

素材はゲームに**自動の受け入れツール**で取り込みます。ツールはファイル名・透過・寸法・コマ数を機械的に検査し、合格したものはそのままゲームに入ります。手直しなしで入るよう、次のルールで納品してください。

■ 1. まとめ方
- 完成したものから、**小分けのZIP**で納品してください。名前は `maougun_assets_batch01.zip`、`batch02`… の通し番号にしてください。
- ZIPの中は、依頼書のファイル名とフォルダのままにしてください。
  - 例：`humans/militia.png`、`bases/watchtower_0.png`
  - ほかの階層の中に入っていても構いません（例：`batch01/humans/militia.png`）。
- 依頼書にないファイル名は取り込みません。名前の綴り（小文字・アンダーバー）をそのままにしてください。
- 修正版は**同じファイル名**で、新しいバッチに入れてください（後から届いたものが優先されます）。

■ 2. 検査される点（不合格になると取り込まれません）
1. **形式**：PNG（RGBA、透過付き）であること。JPEG・WebP は不可です。
2. **背景の透過**：キャラクター・建物・顔・エフェクトは、画像の**四隅が完全に透明**であること。
   - 白や単色の背景が残っていたら不合格です。
   - 影・地面・文字・枠も入れないでください。
3. **透明な部分の量**：画像全体のおよそ15%以上が透明であること（背景の消し忘れを見つけるため）。
4. **コマ数と比率**：キャラクターは1コマの大きさ×コマ数の**横一列**であること。

   | 種類 | 1コマ | コマ数 |
   |---|---|---|
   | 兵士・魔王軍ユニット | 256×256 | 4（静止画1枚も可） |
   | 勇者 | 384×384 | 6（4も可、静止画1枚も可） |
   | 幹部 | 384×384 | 16（静止画1枚も可） |

   - 全体の横幅＝1コマの幅×コマ数になるようにしてください。コマの間に余白や区切り線を入れないでください。
5. **縦横比**：建物・背景・顔は、依頼書の縦横比であること。大きいぶんには構いません。

■ 3. 位置をそろえる約束（見た目をそろえるため）
- **向き**：人間軍は**右向き**、魔王軍は**左向き**です。全コマで同じ向きにしてください。
- **足元**：各コマの**横の中央・下端から16px上**に、足の裏（浮いているキャラは影の位置）をそろえてください。コマごとに上下させないでください（動きはゲーム側で付けます）。
- **大きさ**：同じ種類の中では、キャラの大きさの基準をそろえてください。兵士6種は、同じ背丈の人物として描いてください（騎兵は馬のぶん大きくて構いません）。
- **建物**：足元＝画像の下端の中央です。下に余白を入れないでください。3段階（無傷・ひび・崩れかけ）は、構図と大きさを変えずに描いてください。

■ 4. 一緒に付けてほしいもの
- **確認シート**（`preview_batchNN.png`）：そのバッチの全素材を並べた1枚。ユーザー承認の確認用で、ゲームには使いません。
- **一覧**（`manifest.csv`）：1行1ファイルで、次の列を入れてください。

  `ファイル名, コマ数, 1コマの幅, 1コマの高さ, 向き, ユーザー承認(済/未), 備考`

  - 透過やコマ数に不安があるもの、未完成のものは「備考」に書いてください。そう書かれたものは、取り込まずに報告します。

■ 5. 優先して納品してほしい順
1. **batch01**：
   - 人間軍の兵士6種（承認済み）`humans/militia.png`、`swordsman.png`、`archer.png`、`shield.png`、`priest.png`、`rider.png`
   - 見張り小屋 `bases/watchtower_0〜2.png`
   - 封印の祠 `bases/shrine_0〜2.png`
2. **batch02**：勇者たけ・サイ `humans/take.png`・`sai.png`、会話の背景 `bg/shrine_room.png`（人物なし）
3. **batch03**：会話の顔 `talk/…`、村の門・城 `bases/gate_*`・`castle_*`
4. **batch04 以降**：ステージ別の背景、エフェクト、UI、戦利品アイコン

コマの連番がまだ無い場合は、**静止画1枚（1コマ）だけでも先に納品してください**。待機・移動・攻撃・被弾・撃破・召喚の動きはゲーム側で付けるので、すぐに画面に出せます。連番は、あとから同じファイル名で差し替えられます。

■ 6. 受け入れ後の流れ
- Claude Code が検査結果の表（合格・不合格と理由）を返します。不合格の理由は「四隅が不透明」「コマ数・比率が違う」など具体的に出るので、その点だけを直して再納品してください。
- 合格した素材は、ゲームの画面のスクリーンショットで確認できます。見た目の最終判断は、ユーザーがしてください。
