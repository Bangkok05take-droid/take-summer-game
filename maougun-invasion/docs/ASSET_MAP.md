# 素材の組み込み先と状態（承認デザイン正本 v1 を基準・2026-11-23）

## 担当
- **ChatGPT**：すべてのビジュアルデザインの制作
- **ユーザー**：デザインの最終承認
- **Claude Code**：承認済み素材のゲームへの組み込み（拡大縮小・配置・アニメーション処理のみ。外見は変えない）

Claude Code は今後、キャラクター・背景・UI のデザインを新しく作らない。
今の画面に出ている仮のドット絵・図形（`js/render/pixelart.js`・`backdrop.js`・`shapes.js`）は、承認済み素材が届くまでの一時的な表示で、これ以上は追加・変更しない。

## 組み込みのしかた
1. ChatGPT は [CHATGPT_DELIVERY.md](CHATGPT_DELIVERY.md) のルールで、ZIP を小分けに納品する。
2. 受け入れ：`python3 -I tools/accept_assets.py <ZIP>`（`--dry-run` で検査だけ）
   - 依頼書のファイル名の素材だけを検査する（PNG か・四隅が透明か・透明な部分の量・コマ数と比率・縦横比）。
   - 合格した素材を、**元のバイト列のまま** `assets/approved/` にコピーする。
   - 自動で登録する種類は `js/data/approved.js` に書く。`skin.js` が読み込み、その場所だけ仮の表示から差し替わる。
     - 自動で登録：人間軍・勇者・建物（3段階）・背景・会話の背景・人間側の顔・エフェクト（11種）・UI（ロゴ・カード枠・パネル枠・呪文ボタン・魔力と魔界石のアイコン・戦利品アイコン）。
     - 取り込みのみ：魔王軍のユニット・幹部・大魔王と側近の顔。ツールが `skin.js` に足す1行を表示する。登録はプロジェクトの持ち主が行う。
   - 検査の結果は `docs/reports/accept_*.md` に、出どころは `docs/ASSET_SOURCES.md` に自動で残る。元の ZIP は変更しない。
3. 戦闘ロジック・数値・当たり判定・セーブは変えない。ゲーム側でするのは、拡大縮小・配置・動き（待機・移動・攻撃・被弾・撃破・召喚）だけ。
4. 確認：`npm run test:accept`（ダミーの画像で、受け入れから画面での差し替えまでを通しで確認する）。

### キャラクター素材について
- 承認済みのモンスター・幹部・大魔王・側近のデザインは、既存作品のキャラクターに似ていないことを確認したオリジナルに限ります。
- Claude Code は承認済みの画像を加工せずに組み込みます（描き直し・切り抜きはしない）。
- 透過済みの連番が届いた場合、`js/data/skin.js` の `sprites` に1枠1行で登録すれば、そのまま戦闘・カード・解放画面に出ます。登録はプロジェクトの持ち主側で行ってください。
- 公開版では、権利処理または独自のキャラクターへの置きかえが必要です（README_FIRST_CLAUDE.md にも記載あり）。
