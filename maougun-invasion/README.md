# 魔王軍の世界侵略（仮）

にゃんこ大戦争型（横スクロールのレーン防衛・侵略）の、スマホブラウザ向けゲーム。
プレイヤーは魔王軍。魔力を使って魔物を召喚し、魔物は自動で進軍・攻撃する。
人間軍の拠点を壊せば勝ち、こちらの「封印の祠」を壊されたら負け。ビジュアルは「かわいいダークファンタジー」。

> **状態：立ち上げ段階（ゲーム本体は未実装）。** 調査結果と開発構成の提案だけを置いています。

## 既存ゲームとの関係
- 素材の出どころ：『たけとサイの大冒険 〜アユタヤの夢見る遺跡〜』
  （リポジトリ `Bangkok05take-droid/take-sai-adventure`、ブランチ `claude/take-sai-adventure-game-loh1fe`、調査時のコミット `15ccbd7`）
- 既存プロジェクトは**読むだけ**。変更・削除はしない。必要な素材は本プロジェクトへ**コピー**して、出どころを `docs/ASSET_SOURCES.md`（作成予定）に記録する。
- 本プロジェクトは独立して動く（既存ゲームのファイルを実行時に参照しない）。
