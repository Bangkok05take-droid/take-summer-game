# 魔王軍の世界侵略（仮）

にゃんこ大戦争型（横スクロールのレーン防衛・侵略）の、スマホブラウザ向けゲーム。
プレイヤーは魔王軍の指揮官。魔力で魔物を召喚し、魔物は自動で進軍・攻撃する。
人間軍の拠点（右）を壊せば勝ち、こちらの「封印の祠」（左）を壊されたら負け。ビジュアルは「かわいいダークファンタジー」。

> **状態：試作版（ステージ 1-1「見張り小屋」が遊べる）。** 絵は図形の仮の絵です。

## 遊び方（起動）
ビルド不要の静的ページです。依存パッケージはありません。
```sh
cd maougun-invasion
node tests/serve.js 8080      # → http://localhost:8080/
```
- スマホは横持ち。下のボタンで召喚、左下「魔力炉」で魔力の上限と回復を強化、右下「魔王の呪文」がたまったら範囲攻撃。
- 戦場はドラッグ（または上の小さな地図のタップ）で左右に動かせます。右上で 2倍速・一時停止。
- PC：1〜4 召喚／Q 魔力炉／Space 呪文／←→ 移動／S 速度／P 一時停止／R 結果画面でやり直し。
- URL に `?seed=数字` を付けると、同じ乱数で遊べます（不具合の再現用）。

## テスト
```sh
npm test               # 戦闘ロジック（19件）
npm run e2e            # スマホ横画面の操作（Playwright・23件）。node tests/e2e.test.js <保存先> でスクリーンショットも保存
npm run balance        # ボットで 1-1 のクリア時間を確認
```
